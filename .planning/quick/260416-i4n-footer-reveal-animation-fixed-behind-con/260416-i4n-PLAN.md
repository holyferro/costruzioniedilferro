<objective>
Implement the "fixed behind content" footer reveal pattern. The footer is positioned fixed at the bottom of the viewport at z-index 0. The page content sits in a z-index 10 wrapper with the same background color (bg-panna), so it visually covers the footer while the user has not yet scrolled to the bottom. A spacer div — whose height is dynamically synced to the footer's rendered height — ensures the page accumulates enough scroll distance to fully expose the footer. An upward box-shadow on the footer element gives depth.

Purpose: Creates a premium reveal effect consistent with the "sobrio, istituzionale" brief without any animation library. Pure CSS layering + one tiny ResizeObserver Client Component.
Output: FooterReveal.tsx (new), layout.tsx (modified), globals.css (modified — removes conflicting CSS scroll-driven animation).
</objective>

  <name>Task 1: Create FooterReveal Client Component</name>
  <files>components/layout/FooterReveal.tsx</files>
  <action>
Create a new Client Component (`"use client"`) at `components/layout/FooterReveal.tsx`.

The component:

- Accepts `children: React.ReactNode`
- Creates a `wrapperRef = useRef<HTMLDivElement>(null)`
- In `useEffect`, attaches a `ResizeObserver` to `wrapperRef.current` that reads `entry.borderBoxSize[0].blockSize` (or falls back to `wrapperRef.current.offsetHeight`) and writes it to `document.documentElement.style.setProperty('--footer-height', height + 'px')`
- Runs the measurement once on mount synchronously (before the observer fires its first callback) using `wrapperRef.current.offsetHeight` to prevent a flash of incorrect spacer height
- Cleans up the observer in the effect's return function
- Renders:

```tsx
<div ref={wrapperRef} className="fixed right-0 bottom-0 left-0 z-0" aria-hidden="false">
  {children}
</div>
```

Do NOT use `position: sticky` or any other positioning — it must be `fixed`. Do NOT add any animation classes here; the reveal is purely a layering effect.

Named export: `export function FooterReveal`.
</action>
