**Step A — Creare 4 route stub RSC:**

Per ognuna delle route (`/servizi`, `/progetti`, `/chi-siamo`, `/contatti`) creare un file `page.tsx` minimo nella directory `app/{route}/`. Le directory non esistono — vanno create.

Ogni stub deve:

- Essere un RSC (nessun `"use client"`)
- Usare named export (non default anonimo)
- Mostrare un titolo placeholder riconoscibile
- Non importare nulla che non esista già

**Step B — Riabilitare typedRoutes in next.config.ts:**

Modificare `next.config.ts` decommentando `typedRoutes: true`:

```typescript
import type { NextConfig } from "next";

const nextConfig: NextConfig = {
  // typedRoutes abilita il type-checking dei <Link href> — riabilitato in Phase 2
  // ora che tutte le route primaryNav esistono: /servizi /progetti /chi-siamo /contatti
  experimental: {
    typedRoutes: true,
  },
};

export default nextConfig;
```

**ATTENZIONE:** `typedRoutes` in Next.js 16 si trova sotto `experimental`. Verificare con `pnpm typecheck` dopo la modifica — se Next.js 16 ha spostato l'opzione fuori da `experimental`, usare `typedRoutes: true` al livello root del config invece.

**Step C — Verificare il typecheck:**

Le route `/privacy` e `/cookie-policy` in `footerNav` non hanno ancora pagine — se causano errori TypeScript con typedRoutes, aggiungere anche i loro stub.
