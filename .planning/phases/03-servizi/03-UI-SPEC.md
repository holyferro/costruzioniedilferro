# Phase 3 — UI Design Contract

> Phase 3 does NOT introduce a new design system. It extends the Phase 1 token set and reuses the Phase 2 editorial language on a panna/white canvas.

| H3 (step / sub-section)      | clamp(1.3rem, 0.6rem + 1vw, 1.65rem) → ~21–26px            | IBM Plex Serif | 500 (`font-medium`)   | 1.25                    | "Come lavoriamo" step title, sub-heading inside target card                                                                                                      |
| H2 (editorial section title) | clamp(1.75rem, 0.8rem + 2vw, 2.6rem) → ~28–42px            | IBM Plex Serif | 500                   | 1.15                    | Titolo di ciascuna sezione target (Privati / Enti Pubblici / Professionisti) — matches ServiceRow H3 style from Phase 2                                          |
| H1 (page hero)               | clamp(2.25rem, 1.5rem + 3.2vw, 4rem) → 36–64px             | IBM Plex Serif | 500 (`font-medium`)   | 1.1 (`text-h1` token)   | Titolo hero pagina — ONE per page                                                                                                                                |

**Rules:**

- Serif (`font-serif`) is reserved for hero H1, section H2, and editorial H3 only (Phase 1 D-08).
- Inter is the default body font; it renders via the `body` rule in `globals.css` — do not add explicit `font-sans` on body paragraphs.
- Neue Montreal (`font-[family-name:var(--font-neue-montreal)]`) is used only on CTA labels, index links, and uppercase micro-copy (kicker + eyebrow secondary) — identical to Phase 2 pattern.
- No italic on body. Italic is a display-only emphasis on H2 accent words (`<em className="text-brand font-serif italic">`) or on numbered meta (`— 01`).
- Maximum of 4 serif clamps in use on a single page. Do not introduce a 5th scale.
- `font-semibold` (600) is permitted **exclusively** on uppercase micro-copy ≤12px (eyebrow, kicker, SOA badge code) — never on body paragraphs, never on H1/H2/H3 base text.

## SOA Badge Specification (D-08 — Phase 3 critical differentiator)

SOA badges MUST be visually distinct from ordinary bullet pills, or the critical differentiator collapses into the background. Treat them as a first-class visual primitive for the Enti Pubblici section only.

| Property      | Value                                                                                                                                                                                                                      | Rationale                                                               |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| Container     | 3-column row on desktop (`md:grid-cols-3`), stacked on mobile (`grid-cols-1`), `gap-4 md:gap-6`                                                                                                                            | Each category is peer-equal; prevents "buried in prose"                 |
| Surface       | `bg-white` on `bg-panna` sections OR `bg-panna` on `bg-surface` sections (always contrast 1 level up) + `border border-border` + `rounded-lg` (8px)                                                                        | Distinct from bullet pills (which are pill-shaped)                      |
| Padding       | `px-5 py-4 md:px-6 md:py-5`                                                                                                                                                                                                | Breathing room appropriate for a certification card                     |
| Badge code    | `OG1` / `OG2` / `OG3` in Neue Montreal, `text-xs font-semibold tracking-[0.22em] uppercase`, color `text-brand` (fill-only rule: this is micro-copy on neutral surface, NOT adjacent to a dark title — explicitly allowed) | Echoes SOA token already used in TrustStrip (Phase 2 `trustStrip.rows`) |
| Category name | IBM Plex Serif `text-lg md:text-xl font-medium` color `text-ink`, positioned directly under the badge code                                                                                                                 | Readable Italian name, e.g. "Edifici civili e industriali"              |
| Description   | Inter `text-sm leading-[1.55] text-ink/70`, max 1–2 lines                                                                                                                                                                  | Plain-Italian explanation of what the category covers                   |
| Placement     | Inside the Enti Pubblici editorial section, BELOW the bullet-service list, ABOVE any section-end CTA                                                                                                                       | Reinforces "these are the credentials behind the bullet list above"     |

**Strict:** SOA badges are used **only** in the Enti Pubblici editorial section. They are NOT reused in the target index card preview. The index card mentions "SOA OG1 · OG2 · OG3" as a single line of meta-copy (mirrors existing TrustStrip treatment) — full badges appear only once on the page, in the detailed section, preserving the visual hierarchy.
